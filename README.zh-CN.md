# Pictether

![Language support](https://img.shields.io/badge/Language-English%20%7C%20Chinese-blue)

[English](README.md) · **简体中文**

**让笔记库保持清爽，让附件井然有序。**

Pictether 是一款简洁、本地优先的 Obsidian 桌面端外部附件管理插件。自然地粘贴、拖入和管理图片、视频与 PDF，同时将它们有序地保存在笔记库之外。

## 为什么选择 Pictether？

- **简单直接。** 设置附件目录即可开始使用，无需复杂配置或额外工作流。
- **按时间整理。** 附件按“仓库名／日期／时分秒-随机后缀”组织，便于浏览、查找和管理。
- **笔记库更清爽。** 大体积媒体文件保存在笔记库外，同时保留熟悉的 Obsidian 编辑体验。
- **按需备份。** 可选用 S3 兼容对象存储备份附件，并恢复本地缺失的文件。
- **便于迁移分享。** 将笔记导出为普通 Markdown，附件使用相对链接。

*笔记留在 Obsidian，附件有序存放。*

## 使用

1. **选择附件目录。** 在插件设置中填写附件根目录，默认是当前用户主目录下的 `Pictures/markdown-assets`。仓库名自动读取 Obsidian。
2. **插入附件。** 将图片、视频或 PDF 粘贴、拖入笔记，或执行“插入附件”命令，在阅读视图或实时预览中查看。
3. **连接对象存储。** 填写 S3 服务地址和存储桶。点击“RK 访问凭据”旁的加号，输入 Access Key ID 和 Secret Access Key，测试连接后保存。Cloudflare R2 的签名区域使用 `auto`，不需要填写 Token value。
4. **开启自动备份。** 自动备份已有及新增附件。凭据右侧的三个点菜单提供编辑和删除操作；灰点表示未测试，红点表示连接测试失败，绿点表示测试通过。“今日概览”展示备份次数、成功、冲突和失败数量。
5. **恢复缺失附件。** 本地缺失的文件可从云端恢复，也可在设置中点击“恢复缺失附件”，或执行同名命令。内容发生冲突时不会自动覆盖文件。
6. **导出笔记。** 执行“导出笔记与附件”，生成普通 Markdown 和相对附件链接，便于其他工具读取。

## 兼容性

Pictether 目前**仅支持 Obsidian 桌面端**。

界面跟随 Obsidian 的语言设置：中文环境使用简体中文，英文和其他语言环境使用英文。无需单独设置插件语言。更改 Obsidian 语言后，请按其提示重新加载。

**支持格式：**

- **图片：** PNG、JPEG、WebP、GIF、BMP、AVIF、SVG。
- **视频：** MKV、MOV、MP4、OGV、WebM。能否播放取决于编码。
- **文档：** PDF。

新导入的 JSON 和 Markdown 文件交给 Obsidian 处理。暂不支持音频、HEIC 和 TIFF。

## 注意事项

附件使用 `mdasset://` 引用，原始笔记中的附件显示依赖 Pictether。需要分享给其他 Markdown 工具时，请使用导出功能。

仅使用本地附件时无需配置云端存储。连接测试通过不代表已验证上传权限。

### 重置提醒

**重置会删除当前附件根目录下所有命名空间的受管理本地附件，包括共用此目录的其他笔记库的附件。未备份的文件无法恢复。**

请核对目录与文件数量后再确认。笔记和云端文件保留，之后可重新配置对象存储，恢复已备份的附件。
